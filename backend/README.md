# Music X — Backend (FastAPI)

Python + FastAPI API layer for Music X. Talks to Supabase (Postgres), holds all
secret API keys, and runs the event verification pipeline.

## Run locally

    source .venv/bin/activate
    fastapi dev app/main.py

API: http://127.0.0.1:8000  ·  Docs: http://127.0.0.1:8000/docs
